## 一 产品结论

建议建设一款以可视化工作流为核心的 AI 素材生成平台。产品采用无限画布承载文本、图片、视频、上传素材和生成结果，用户通过连线明确上下游依赖，并以单节点或整条工作流方式执行。MVP 先完成图像素材与分镜转视频两条主链路，再扩展音频、多人协作和模板市场。

参考流程把画面设计和运动生成分成两个阶段。图像节点用于固定角色、构图、风格与关键帧；视频节点读取关键帧、分镜及运动描述后生成视频。该拆分能让失败定位、版本对比和局部重试更清晰。[1]

## 二 背景与用户问题

### 二点一 现状

现有 AI 素材工具通常按模型或媒介分散。创作者需要在文本工具、图像工具、视频工具和本地文件夹之间反复复制提示词、下载结果并重新上传。素材之间的来源关系、参数版本和修改理由难以追踪，团队也无法稳定复用一条已经验证的生产流程。

### 二点二 核心问题

| 问题 | 用户表现 | 产品机会 |
| --- | --- | --- |
| 上下文分散 | 提示词、参考图和输出散落在不同工具 | 在画布中保留输入、输出和连线关系 |
| 视频可控性不足 | 直接文生视频时角色、构图和镜头衔接不稳定 | 先生成关键帧或分镜，再执行图生视频 |
| 迭代成本高 | 任何修改都可能迫使用户重跑整条链路 | 支持节点级版本、分支、缓存和局部重试 |
| 结果不可复用 | 优秀提示词和参数停留在个人历史记录 | 将画布保存为模板并支持变量化 |
| 成本不可见 | 提交后才知道耗时或算力不足 | 运行前估算成本，运行中显示进度，失败后说明退款规则 |

## 三 产品目标与范围

### 三点一 产品目标

- 让新用户在 10 分钟内从空白画布生成第一张可下载图片，并理解节点与连线的基本心智模型。

- 让用户在一个项目内完成创意描述、分镜图生成、视频生成、版本对比与导出，不依赖手工搬运中间文件。

- 让每次生成可追溯到输入版本、模型参数、上游素材和执行记录，便于复现与团队复盘。

- 通过模板、缓存、局部重跑和成本预估降低重复生成与无效消耗。

### 三点二 非目标

- MVP 不提供专业非线性视频剪辑、多轨时间线、逐帧合成或复杂调色。

- MVP 不训练自有基础模型，平台通过标准适配层接入外部图像与视频模型。

- MVP 不承诺不同供应商之间完全一致的参数或输出质量，界面展示模型能力差异。

- MVP 不建设公开社交社区；分享仅覆盖受控链接、模板复制和项目协作。

### 三点三 版本范围

| 能力 | MVP | 后续 |
| --- | --- | --- |
| 画布 | 项目、节点、连线、缩放、对齐、撤销重做、自动保存 | 多人光标、评论、演示模式 |
| 素材 | 上传、资产库、标签、搜索、下载 | 品牌资产包、团队资产权限 |
| AI 生成 | 文本、图像生成与编辑、分镜规划、图生视频 | 音频、数字人、视频后处理 |
| 执行 | 节点运行、下游运行、全量运行、取消等待、重试 | 定时运行、批处理、外部触发 |
| 复用 | 复制节点、保存模板、模板变量 | 公开模板市场、收益分成 |
| 商业化 | 配额或算力预扣、失败返还、用量记录 | 团队预算、成本中心、合同计费 |

## 四 用户与使用场景

### 四点一 核心用户

| 用户 | 主要任务 | 成功标准 |
| --- | --- | --- |
| 内容创作者 | 制作短视频、封面、海报和系列内容 | 更少切换工具，能快速试多个创意方向 |
| 品牌营销 | 生成品牌一致的广告图与短视频 | 人物、产品、文字与品牌视觉可控 |
| 影视与游戏团队 | 制作概念图、角色设定与分镜预演 | 镜头顺序、转场动机和场景连续性可复现 |
| 教育与培训 | 生成步骤图、动作分解和教学短片 | 内容结构清楚，能逐节点修改 |
| AI 运营人员 | 维护模型、模板、成本和安全策略 | 供应商切换不影响用户项目 |

### 四点二 优先场景

1.  产品广告。用户输入品牌、商品、受众、视觉风格和镜头顺序，先生成多格分镜，再生成横版或竖版广告视频。

2.  电影短片预演。用户为每个镜头定义焦段、机位、主体动作、时长和转场动机，生成可供视频模型理解的分镜图。

3.  社交媒体套图。用户从一个主题生成封面与多页内容卡，后续页面继承封面的视觉参考。

4.  创意对比。同一输入分叉为多种风格或模型，生成多个候选版本并在画布上并排比较。

5.  素材再编辑。用户从资产库拖入历史图片，局部修改背景、文案、构图或比例，并保留原版本。

## 六 核心用户流程

### 六点一 新建并生成图片

| 步骤 | 用户操作 | 系统反馈 |
| --- | --- | --- |
| 1 | 新建空白项目或选择模板 | 打开可编辑画布并完成本地或云端自动保存 |
| 2 | 添加文本节点，输入创意简报 | 实时保存内容并提示可连接的下游节点 |
| 3 | 连接图片节点并选择模型参数 | 解析上游引用，展示预计成本与不兼容项 |
| 4 | 点击生成 | 冻结本次输入快照，显示排队、生成和上传进度 |
| 5 | 查看结果并生成变体 | 保留多个版本，可设为当前版本或继续向下游连接 |
| 6 | 保存到资产库或下载 | 记录来源链路、格式、尺寸和生成参数 |

### 六点二 分镜转视频

默认模板包含创意简报、分镜规划、分镜图生成和视频生成四个节点。分镜规划节点将自然语言拆成镜头列表；图像节点把镜头列表排成多格分镜或生成关键帧；视频节点重点描述动作、镜头运动、节奏和转场。

| 阶段 | 输入 | 输出 | 检查点 |
| --- | --- | --- | --- |
| 定义画面 | 品牌、人物、场景、风格、比例 | 结构化创意简报 | 人物与商品描述无冲突 |
| 规划镜头 | 创意简报、总时长 | 镜头列表和时间轴 | 每个镜头有主体、景别、动作和时长 |
| 生成分镜 | 镜头列表、参考素材 | 多格分镜或关键帧组 | 人物、产品、文字与画风一致 |
| 生成视频 | 分镜、运动提示词 | 视频候选版本 | 运镜有动机，镜头顺序与节奏符合脚本 |
| 迭代导出 | 问题定位和修改 | 最终素材与追溯记录 | 仅重跑受影响的节点 |

### 六点三 分支对比

用户可从任意节点创建分支。系统复制节点配置但不复制二进制文件，并复用未变化的上游结果。对比视图同时显示提示词差异、模型参数、生成耗时、成本和结果缩略图。用户可以选择一个分支为主线，也可以保留多个候选方案。

## 八 业务规则与状态

### 八点一 连线兼容规则

| 源输出 | 允许目标 | 规则 |
| --- | --- | --- |
| 文本 | 文本、图片、视频、分镜 | 作为提示词或结构化上下文，按用户指定顺序合并 |
| 图片 | 图片、视频、分镜 | 映射为参考图、待编辑图、首帧或尾帧 |
| 视频 | 视频、分镜 | 仅在目标模型支持参考视频或视频编辑时允许 |
| 音频 | 视频、音频 | 仅在目标模型支持参考音频或音频条件时允许 |
| 镜头列表 | 图片、视频 | 图片节点生成分镜图；视频节点生成镜头运动描述 |

### 八点二 运行快照

点击运行后，系统冻结节点配置、上游版本、模型能力版本、内容安全策略版本和成本报价。画布后续编辑不会改变已经提交的任务。完成结果必须关联该快照，用户因此可以复现或解释一次生成。

### 八点三 缓存规则

- 缓存键由供应商、模型版本、规范化参数、提示词、上游素材内容哈希和策略版本组成。

- 命中缓存时默认复用已有结果，不重复扣费；用户可显式选择强制重新生成。

- 含随机种子但供应商不保证确定性的请求仅标记为近似复现，不承诺像素一致。

- 素材权限、生命周期或安全状态变化时，相关缓存必须失效。

### 八点四 删除与引用

删除节点仅从当前画布移除节点；其生成记录和已被其他节点引用的素材进入归档。删除素材记录前，系统列出引用项目和节点。MVP 使用软删除与回收站，默认保留 30 天；企业策略可覆盖该期限。

## 九 验收标准

### 九点一 端到端验收

| 场景 | 前置条件 | 验收结果 |
| --- | --- | --- |
| 首次文生图 | 新用户有可用额度 | 10 分钟内完成新建项目、生成、预览和下载；失败时收到可执行提示 |
| 分镜转视频 | 已有创意简报 | 镜头规划、分镜图和视频三类输出均保留来源链；仅修改一个镜头时无需重跑无关节点 |
| 断网恢复 | 编辑中断网 3 分钟 | 本地编辑不丢失；恢复后提示合并结果；不重复提交任务 |
| 任务后台运行 | 视频任务已进入供应商队列 | 关闭页面再进入项目后可看到任务状态和结果 |
| 额度不足 | 余额低于预估成本 | 提交前阻止运行并显示所需、剩余和充值入口 |
| 模型故障 | 主供应商返回可重试错误 | 按策略重试或切换通道；预扣最终只按成功任务结算 |

### 九点二 体验验收

- 所有生成按钮在提交前明确显示执行范围、模型、预计成本和参考素材数量。

- 节点状态不仅依赖颜色，还包含文本与图标，满足色觉辅助需求。

- 键盘用户可以创建节点、切换属性、触发运行和访问错误详情。

- 空画布提供可直接运行的示例，不强制用户先理解全部节点类型。

- 画布中 200 个可见节点时，拖动和缩放的 P95 帧率目标不低于 45 FPS。

### 十点二 内容与权利

- 上传前要求用户确认拥有必要的版权、商标、肖像和声音使用权。

- 文本和图片输入在提交供应商前执行内容安全检查；输出在入库前再次检查。

- 涉及真人肖像、未成年人、政治人物或品牌资产时应用更严格的模型与地域策略。

- 资产记录保留生成来源、模型、时间和编辑链；支持写入 C2PA 或等价来源元数据的供应商优先。

- 管理员可配置留存期、可用模型、出境策略、下载权限和水印策略。

## 十一 指标与埋点

### 十一点一 核心指标

| 层级 | 指标 | 定义与目标 |
| --- | --- | --- |
| 北极星 | 每周成功导出的有效素材数 | 完成下载、保存到资产库或被下游成功消费的去重素材 |
| 激活 | 首次价值时间 | 新用户从进入空画布到首次成功结果的中位数小于 10 分钟 |
| 完成 | 工作流成功率 | 至少一个目标输出节点成功的执行占比；MVP 目标大于 85% |
| 效率 | 局部重跑占比 | 修改后只执行受影响节点的次数占全部重跑次数 |
| 质量 | 结果采用率 | 被下载、保存或进入下游的生成版本占全部成功版本 |
| 成本 | 有效素材单位成本 | 供应商实付成本除以有效素材数 |
| 可靠性 | 生成任务终态覆盖率 | 24 小时内进入可解释终态的任务占比；目标大于 99.5% |

## 十三 风险与待决策项

| 风险或决策 | 影响 | 建议 |
| --- | --- | --- |
| 供应商能力和价格变化 | 节点参数与成本展示失真 | 建立模型能力注册表，不在前端硬编码模型字段 |
| 视频任务长时间无终态 | 用户无法判断是否应重试 | 设置平台超时、供应商对账任务和人工补偿入口 |
| 同一人物跨镜头不一致 | 结果采用率下降 | 提供角色资产、约束锁定和一致性评分，但不承诺绝对一致 |
| 画布规模持续增长 | 浏览器内存和交互性能下降 | 视口虚拟化、缩略图分级、节点内容延迟加载 |
| 临时下载链接过期 | 历史结果不可用 | 成功后转存对象存储并使用平台签名 URL |
| 版权与肖像争议 | 合规和品牌风险 | 权利确认、策略审核、审计日志和投诉处置流程 |
| 额度结算争议 | 退款和客服成本 | 预扣、最终结算、失败返还全部写入不可变账本 |

## 附录二 示例工作流

篮球鞋广告模板

```text
创意简报文本
  ↓
分镜规划节点  生成 9 个镜头与时间轴
  ↓
图像节点  生成 3 乘 3 分镜图并锁定商品和人物
  ↓
视频节点  按镜头顺序生成快切广告
  ↓
结果节点  对比版本 保存素材 下载
```

电影短片模板

```text
场景设定与人物卡
  ↓

  ↓
关键帧组  标注景别 焦段 方向箭头与时间
  ↓
视频节点  连续运镜与焦点交接
  ↓
质量检查  连贯性 人物一致性 物理合理性
```

## 附录三 术语

| 术语 | 定义 |
| --- | --- |
| 当前版本 | 节点在画布上向下游提供的版本；历史版本仍可查看 |
| 运行快照 | 提交任务时冻结的输入、配置、策略和成本信息 |
| 上游素材 | 通过连线或引用进入当前节点的文本、图片、视频或音频 |
| 过期节点 | 上游当前版本变化后，尚未基于新输入重新执行的节点 |
| 转场动机 | 由场景动作或主体移动触发的镜头关注点转移 |
| 有效素材 | 被下载、保存到资产库或被下游成功使用的生成结果 |
